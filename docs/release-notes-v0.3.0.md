# Image-PPT v0.3.0

Image-PPT is now available as a public, bilingual Agent Skill for research-backed image presentations.

Highlights:

- source and claim traceability before deck writing;
- consistent `gpt-image-2` slide generation through style prototypes and a resumable manifest;
- deterministic slide, contact-sheet, and PDF validation;
- explicit support for Codex built-in generation, authorized API use, and honest planning-only degradation;
- CI, monthly dependency checks, issue templates, and public release evidence.

Known limit: a compatible Agent Skills host still needs its own callable `gpt-image-2` route for full generation. Installation alone does not provide image capability.
