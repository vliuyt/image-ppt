# Support

- Reproducible bugs: open a GitHub issue using the bug template.
- Workflow or compatibility proposals: use the feature template.
- Security concerns: follow [SECURITY.md](SECURITY.md).

Include the host runtime, Image-PPT version, selected mode (`codex-built-in`, `openai-api`, or `planning-only`), the failing command, and redacted output. Never include credentials or private presentation content.
