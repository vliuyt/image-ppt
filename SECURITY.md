# Security policy

## Supported version

Security fixes target the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing credentials, private deck content, or an exploitable proof of concept.

Image-PPT must never ask users to paste an API key into chat. API credentials stay in the host's local secret environment. Generated file paths must remain inside the user-selected deck workspace, and PDF assembly accepts only finalized manifest pages.
