# Release evidence

This directory contains compact, public-safe release evidence. Raw local reports, absolute workstation paths, private prompts, and generated deck content are intentionally excluded.

- `output_quality_scorecard.md`: deterministic output-contract evaluation.
- `security_trust_report.md`: trust scan summary.
- `conformance_matrix.md`: adapter conformance summary.
- `release_validation.md`: release-candidate checks and known limits.
