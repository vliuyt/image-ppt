# Changelog

All notable changes are documented here. This project follows semantic versioning.

## [0.3.0] - 2026-08-25

### Added

- Public Image-PPT package with bilingual documentation.
- Capability-based runtime gate for Codex, authorized API, and planning-only modes.
- Research/source provenance contract, style prototypes, resumable manifest, visual QA, and PDF verification.
- Deterministic validators, public-release checks, CI, and monthly dependency review.

### Changed

- Renamed the Skill and public package to Image-PPT / `image-ppt`.
- Clarified that Agent Skills compatibility does not by itself provide image-generation capability.
